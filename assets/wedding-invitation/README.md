# הזמנות חתונה בגלילה - בסימן טוב

ארבע הזמנות, כל אחת קובץ HTML אחד עצמאי. אין תלות בשרת, אין ספריות
חיצוניות, ואין שום קריאה לשירות בתשלום. הדבר היחיד שנטען מבחוץ הוא
הפונטים מ-Google Fonts.

| קובץ | סגנון | התנועה המרכזית בגלילה |
|---|---|---|
| `hazmana-porachat.html` | פרחים ואקוורל, שמנת וזהב | גפני זהב שנמתחות בשוליים, פרלקסת פרחים, עלי כותרת נושרים |
| `layla-shel-zahav.html` | ערב כהה ויוקרתי | קשת זהב שמציירת את עצמה, אורות מרצדים |
| `hogegim-begadol.html` | צבעוני, צעיר ונועז | שני סרטי טקסט שרצים לכיוונים הפוכים, קונפטי, כרטיסים מהצד |
| `seret-ahava.html` | קולנועי, מונוכרום | סרטון מסך מלא + גלריה שנעה הצידה בזמן גלילה למטה |

## איך מחליפים תוכן

כל הטקסטים כתובים ישירות בקובץ. מה שצריך לעדכן בכל הזמנה:

- שמות בני הזוג, התאריך, השעות, שם המקום והכתובת
- שמות ההורים
- מספר הוואטסאפ בקישור `wa.me` - כרגע `972500000000` שהוא מספר דמה
- יעד הניווט בקישור `waze.com`
- תאריך היעד של הספירה לאחור: המשתנה `TARGET` בסוף הקובץ

## איך מכניסים סרטון רקע

בכל קובץ יש תג `<video>` מסומן בהערה. שני צעדים:

1. לשים נתיב לקובץ ב-`src`, למשל `src="video/rekah.mp4"`
2. למחוק את המילה `hidden` מהתג

כשאין `src` הדף מציג רקע מקודד ונראה שלם, אז אפשר להעלות אותו כמו שהוא
ולהוסיף וידאו אחר כך.

ב-`seret-ahava.html` יש חמישה תגי וידאו נוספים בגלריה, אחד לכל פריים.
אותו נוהל: `src` + מחיקת `hidden`. פריים בלי סרטון מציג רקע מקודד.

המלצות לקובץ: mp4 ב-H.264, ברוחב 1080 לכל היותר, מתחת ל-4MB, בלי סאונד
(הסרטונים רצים מושתקים ובלולאה).

## נגישות וביצועים

RTL מלא, ניסוח מגדרי ניטרלי, `prefers-reduced-motion` מכובד בכל הדפים,
focus נראה במקלדת, כפתורים בגובה מגע תקני. נבדק שאין גלילה אופקית
ב-390px ועד דסקטופ, ושאין שגיאות JavaScript.
