# העוזר הקולי 🎙️

> **יש כאן שתי גרסאות:**
> - **[ג'רוויס בעברית](jarvis-he/)**: הפרויקט מהפוסטים, עם ממשק איירון מן. המוח הוא Claude Code, כך שהוא רץ על מנוי ה-Claude בלי מפתח API. הקול העברי הוא הקול החינמי של Windows.
> - **העוזר שבתיקייה הזאת**: עוזר עברי פשוט, עם קול טבעי ומהיר של OpenAI (Realtime). צריך מפתח OpenAI, ומשלמים לפי שימוש.

עוזר קולי אישי למחשב: מדברים איתו בעברית, והוא עונה בקול טבעי ויודע גם לעשות דברים במחשב.

**מה הוא יודע לעשות**
- שיחה חופשית בעברית, ואפשר לקטוע אותו באמצע משפט
- לפתוח תוכנות (וורד, כרום, וואטסאפ, פרמייר, CapCut וכל מה שמופיע בתפריט התחל), אתרים ותיקיות
- לחפש בגוגל, ביוטיוב ובמפות, ולצלם מסך
- לחפש ברשת ולענות בעל-פה: מזג אוויר, חדשות, שעות פתיחה, מחירים
- לשלוט בווליום ובמוזיקה (הגברה, השתקה, שיר הבא)
- לרשום פתקים ולהקריא אותם, טיימרים ותזכורות
- לפנות בלשון ניטרלית, נקבה או זכר, לפי ההגדרות

## איך זה בנוי

| חלק | מה עושה אותו |
|---|---|
| אוזניים, מוח ופה | המודל הקולי של OpenAI (Realtime, `gpt-realtime`) שומע את הדיבור ועונה בקול בלי שלב ביניים של המרה לטקסט ובחזרה, ולכן הוא מהיר ואפשר לקטוע אותו |
| ידיים | `assistant.py`: תוכנת Python קטנה שרצה במחשב ומבצעת את הפעולות |
| חלון | דף בעברית שנפתח כחלון נפרד של Chrome או Edge: כדור שמגיב לקול, תמליל ותיבת כתיבה |
| חיפוש ברשת | ה-Responses API של OpenAI עם כלי החיפוש שלו |

מפתח ה-OpenAI לא יוצא מהמחשב. החלון מקבל רק מפתח שיחה זמני, שתוקפו כמה דקות.

## התקנה (פעם אחת, כ-3 דקות)

1. להוריד את התיקייה `voice-assistant` ולשמור אותה במקום קבוע (למשל ב"מסמכים").
2. לחיצה כפולה על **`start.bat`**.
   - אם Python לא מותקן, הקובץ מתקין אותו לבד (דקה בערך).
   - אם Windows מציג אזהרה כחולה: "מידע נוסף" ← "הפעל בכל זאת".
3. בחלון שנפתח, להדביק **מפתח OpenAI**: נכנסים ל-[platform.openai.com/api-keys](https://platform.openai.com/api-keys) ← Create new secret key. באותו מסך אפשר לבחור שם, קול וצורת פנייה.
4. בפעם הראשונה הדפדפן שואל אם לאפשר מיקרופון: לאשר.

נפתח גם חלון שחור ממוזער: זה המנוע של העוזר. צריך להשאיר אותו פתוח (ממוזער זה בסדר). סגירה שלו מכבה את העוזר.

## שימוש

- **לחיצה על הכדור** פותחת שיחה, ולחיצה נוספת מסיימת. בזמן שהעוזר מדבר, לחיצה (או פשוט להתחיל לדבר) עוצרת אותו.
- **Ctrl + Alt + Space** מכל מקום במחשב עושה אותו דבר, גם כשהחלון סגור (כל עוד החלון השחור פתוח).
- אפשר גם להקליד בתיבה שלמטה.
- "תודה, זהו" או "ביי" מסיימים את השיחה.

## כמה זה עולה

התוכנה חינמית. משלמים ל-OpenAI לפי שימוש, מהיתרה בחשבון OpenAI:
- שיחה: בערך בין כמה אגורות לכמה עשרות אגורות לדקת דיבור עם `gpt-realtime`. עם `gpt-realtime-mini` (בהגדרות) זה זול בערך פי שלושה.
- חיפוש ברשת: כמה סנטים לחיפוש.
- כדי לא לשלם על קו פתוח, השיחה נסגרת לבד אחרי 3 דקות שקט (אפשר לשנות), וכפתור ההשתקה מפסיק את ההאזנה.
- כדאי להגדיר תקרת הוצאה חודשית בהגדרות החיוב של OpenAI.

המחירים המדויקים מופיעים בדף התמחור של OpenAI, והם משתנים מדי פעם.

## פרטיות

- הקול והשיחה עוברים לעיבוד אצל OpenAI, כמו בכל עוזר קולי מבוסס AI. לפי המדיניות של OpenAI, מידע שעובר דרך ה-API לא משמש לאימון מודלים כברירת מחדל.
- המפתח, ההגדרות והפתקים נשמרים רק במחשב, בתיקייה `%APPDATA%\VoiceAssistant`.
- התוכנה מאזינה רק למחשב עצמו (127.0.0.1) ולא לרשת, ודפי אינטרנט אחרים לא יכולים להפעיל אותה.

## התאמה אישית

בקובץ `%APPDATA%\VoiceAssistant\config.json` (נפתח בפנקס רשימות):

```json
"apps": {
  "תיקיית הלקוחות": "D:\\Clients",
  "האתר שלי": "https://master-video.co.il"
},
"hotkey": "ctrl+shift+j",
"browser": "edge"
```

- `apps`: שמות משלכם לתוכנות, קבצים, תיקיות או אתרים ("לפתוח את תיקיית הלקוחות").
- `hotkey`: קיצור מקלדת אחר.
- `browser`: `chrome`, `edge` או `default`.

אחרי שינוי בקובץ: לסגור את החלון השחור ולהפעיל שוב את `start.bat`.

**הפעלה אוטומטית עם המחשב:** Win+R ← `shell:startup` ← להעתיק לשם קיצור דרך ל-`start.bat`.

## תקלות נפוצות

| מה קורה | מה עושים |
|---|---|
| "אין גישה למיקרופון" | בהגדרות הדפדפן ← פרטיות ← מיקרופון: לאפשר ל-`127.0.0.1` |
| "נגמרה היתרה בחשבון ה-OpenAI" | להוסיף קרדיט בעמוד ה-Billing של OpenAI |
| Ctrl+Alt+Space לא עובד | תוכנה אחרת תפסה את הקיצור: לבחור אחר ב-`hotkey` |
| תוכנה לא נפתחת | להגיד את השם כמו שהוא מופיע בתפריט התחל, או להוסיף אותה ל-`apps` |
| משהו אחר | הפרטים נרשמים ב-`%APPDATA%\VoiceAssistant\assistant.log` |

## Mac / Linux

`python3 assistant.py` עובד גם שם: שיחה, אתרים, חיפוש, פתקים וטיימרים. קיצור המקלדת, מקשי המדיה והפעלת תוכנות לפי שם עובדים רק ב-Windows.
