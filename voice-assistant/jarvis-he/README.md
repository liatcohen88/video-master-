# ג'יימס: עוזר קולי בעברית 🤖

אומרים **"היי ג'יימס"** (או מוחאים כפיים פעמיים), הוא מתעורר ועונה בקול. הוא מבוסס על [J.A.R.V.I.S.](https://github.com/gcocenza/jarvis), העוזר בסגנון איירון מן שמסתובב ברשת, והמוח שלו הוא Claude Code. לכן הוא רץ על מנוי ה-Claude הקיים, בלי מפתח API ובלי חשבון נוסף.

## התקנה (פעם אחת, כמה דקות)

1. להוריד את `jarvis-he.zip` ולחלץ אותו: לחיצה ימנית ← "חלץ הכל" (Extract All).
2. בתיקייה שנפתחה: לחיצה כפולה על **`INSTALL-JAMES.bat`**.
3. לחכות. ההתקנה עושה הכול לבד, ובסוף ג'יימס נפתח.

במהלך ההתקנה:
- אם Windows מזהיר שהקובץ מהאינטרנט: "מידע נוסף" ← "הפעל בכל זאת".
- אם Windows שואל אם לאשר שינויים: "כן".
- אם נפתח חלון של Claude Code: להתחבר עם חשבון Claude (או לסגור אותו אם כבר מחוברים).

## שימוש

- לחיצה כפולה על **ג'יימס** בשולחן העבודה.
- ללחוץ **"הפעלה"**, לאשר את המיקרופון, ולהגיד **"היי ג'יימס"**, או **למחוא כפיים פעמיים**. אפשר גם בנשימה אחת: "היי ג'יימס, מה מזג האוויר מחר?"
- הוא יודע מה השעה והתאריך, ויכול לפתוח דברים בדפדפן: "תפתח ביוטיוב מתכונים לארוחת ערב", "תחפש בגוגל...", "תפתח מפה של...".
- **"עצור"** או **Esc** עוצרים אותו באמצע משפט. **רווח** מאפשר לדבר בלי "היי ג'יימס", ושולח מיד את מה שנאמר.
- **M** משתיק את המיקרופון, **V** משתיק את הקול שלו, **HE / EN** מחליפים שפה.
- החלון השחור הממוזער הוא המנוע שלו. סגירה שלו מכבה אותו.
- אם הוא לא מצליח לענות, הוא אומר "לא הצלחתי לקבל תשובה", והסיבה מופיעה על המסך ובחלון השחור. הפעלה חוזרת של `INSTALL-JAMES.bat` בודקת את החיבור ל-Claude ומתקנת מה שאפשר.

## מה ההתקנה עושה

מתקינה רק מה שחסר: Node.js, Google Chrome, Git (ש-Claude Code צריך ב-Windows), Claude Code והקול העברי של Windows. אחר כך מורידה את J.A.R.V.I.S. (גרסה `c249096`) לתיקייה `%USERPROFILE%\jarvis`, מוסיפה את הגרסה העברית, שואלת את Claude שאלה קצרה כדי לוודא שהוא עונה, ויוצרת קיצור דרך בשולחן העבודה. אם Claude לא עונה, מופיעה הודעה עם הסיבה. אפשר להפעיל את ההתקנה שוב בכל זמן: היא מתקנת ומעדכנת במקום.

## טוב לדעת

- **קול:** הקול העברי החינמי של Windows נשמע קצת רובוטי. קול טבעי יותר אפשרי בהמשך דרך שירות בתשלום.
- **זיהוי דיבור:** Chrome מזהה את העברית, ולכן צריך חיבור לאינטרנט.
- **עלות:** כל שאלה נספרת במכסה של מנוי ה-Claude. ברירת המחדל היא Sonnet 5, שעונה מהר וחוסך במכסה. לשאלות קשות אפשר לבחור בהגדרות (SETTINGS) את Opus 5.
- **בטיחות:** כברירת מחדל הוא רק קורא ומחפש. הוא לא שולח, לא מוחק ולא קונה.
- **מייל ויומן (בהמשך):** חיבורים שהוספתם ב-claude.ai לא נראים לו. צריך להוסיף אותם ל-Claude Code במחשב עצמו.

## לפיתוח: מה יש בערכה

| קובץ | מה זה |
|---|---|
| `INSTALL-JAMES.bat` | מפעיל את ההתקנה |
| `kit/install-jarvis.ps1` | ההתקנה עצמה (PowerShell, UTF-8 עם BOM) |
| `kit/overlay/` | הקבצים ששונו, בגרסתם המלאה, שמועתקים על גרסה `c249096` |
| `kit/jarvis-hebrew.patch` | אותם שינויים כ-patch, לקריאה או ל-`git apply` |
| `kit/start-jarvis.bat` + `kit/open-jarvis.ps1` | ההפעלה היומיומית: מפעיל ופותח חלון Chrome |
| `kit/brain-check.mjs` | בדיקת המוח בהתקנה: שאלה אחת ל-Claude, דרך אותו SDK ואותו מודל שג'יימס משתמש בהם |
| `kit/jarvis.ico` | סמל ה-arc reactor של הקיצור |

השינויים בקוד המקורי:

| קובץ | שינוי |
|---|---|
| `src/lib/i18n.ts` | עברית כשפה שלישית: 73 מחרוזות, בלי "אדוני" ובלי פנייה ממוגדרת |
| `src/lib/fillers.ts` | משפטי ביניים בעברית ("בודק את היומן.", "מחפש.") |
| `src/lib/voice.ts` | זיהוי דיבור ב-`he-IL`, "היי ג'יימס" בכל האיותים, גם "ג'מס" (וגם "ג'רוויס" עובד), השוואות טקסט ששומרות על אותיות עבריות (בלעדיהן דיבור בעברית נזרק כ"הד"), ומשפט נשלח אחרי שקט גם כש-Chrome לא מסיים אותו |
| `src/lib/clap.ts` | מחיאה שנייה מהירה נספרת, בשביל מחיאה כפולה |
| `src/App.tsx` | מחיאת כפיים כפולה מעירה אותו, "עצור", "די", "חכה" עוצרים אותו, השם מזוהה בתחילת פקודה, ותשובה שנכשלה נאמרת בקול במקום שקט |
| `src/lib/tts.ts` | בחירת קול עברי, והודעה ברורה אם אין קול עברי |
| `src/store.ts` | הגרסה העברית נפתחת בעברית |
| `src/ui/Hud.tsx`, `src/ui/Boot.tsx`, `src/ui/Ignition.tsx`, `index.html` | השם J.A.M.E.S., כפתור HE, מסך הפתיחה בעברית, שורות תמליל מימין לשמאל, והודעת שגיאה ארוכה נשארת מספיק זמן כדי לקרוא אותה |
| `bridge/server.mjs` | הדמות היא ג'יימס, מדברת עברית בלי "אדוני" ובפנייה ניטרלית; נתיב `claude.exe` ב-Windows; `JARVIS_BRIDGE_HOST` לשרת מקומי בלבד; כש-Claude Code לא עולה, הסיבה שהוא כתב (למשל חיבור חסר) מגיעה למסך; השעה והתאריך המקומיים בראש כל שאלה; ב-Windows `open_url` במקום כלי ה-Chrome |

| `bridge/whisper.mjs` | מתג לכיבוי התמלול המקומי (אנגלית בלבד) |
| `package.json` | `bridge:writes` עובד גם ב-Windows |
| `scripts/check-i18n.ts` | הבדיקה העצמית מכסה גם עברית |
