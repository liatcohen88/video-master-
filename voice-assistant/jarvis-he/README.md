# ג'רוויס בעברית 🤖

גרסה עברית ל-[J.A.R.V.I.S.](https://github.com/gcocenza/jarvis), העוזר הקולי בקוד פתוח בסגנון איירון מן שמסתובב ברשת. המוח שלו הוא Claude Code. אומרים "היי ג'רוויס", הוא מתעורר ועונה.

- **בלי מפתח API ובלי חשבון נוסף:** רץ על מנוי ה-Claude הקיים. כל שאלה נספרת במכסה של המנוי.
- **עברית:** זיהוי דיבור בעברית (של Chrome), הקול העברי החינמי של Windows, ממשק בעברית, וכפתור HE / EN / PT למעבר שפה בלחיצה.
- **בטוח כברירת מחדל:** קורא ומחפש, לא שולח, לא מוחק ולא קונה.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `jarvis-hebrew.patch` | השינויים לעברית (ושני תיקונים קטנים ל-Windows), על גבי גרסה `c249096` של הפרויקט המקורי |
| `start-jarvis.bat` | לחיצה כפולה מפעילה את ג'רוויס ופותחת אותו בחלון Chrome משלו |
| `open-jarvis.ps1` | פותח את החלון ברגע שהשרת המקומי מוכן (`start-jarvis.bat` מפעיל אותו) |

## התקנה: Claude Code עושה את זה בשבילכם

1. להוריד את התיקייה `jarvis-he` למחשב (למשל ל"הורדות").
2. לפתוח את Claude Code בתוך התיקייה הזאת.
3. להדביק את הפרומפט:

```text
בתיקייה הנוכחית יש ערכה להתקנת J.A.R.V.I.S. בעברית: jarvis-hebrew.patch, start-jarvis.bat ו-open-jarvis.ps1. אני על Windows. תתקין לי את זה צעד אחרי צעד:

1. תוודא שמותקנים Git, Node.js 20 ומעלה ו-Google Chrome. מה שחסר, תתקין עם winget (Git.Git, OpenJS.NodeJS.LTS, Google.Chrome). אם צריך לפתוח טרמינל חדש כדי שהם ייכנסו ל-PATH, תגיד לי.
2. תשכפל את הפרויקט בלי המרת סופי שורות, ותעבור לגרסה שהטלאי נכתב עבורה:
   git clone -c core.autocrlf=false https://github.com/gcocenza/jarvis "%USERPROFILE%\jarvis"
   git -C "%USERPROFILE%\jarvis" checkout c249096
3. תחיל את הטלאי: git -C "%USERPROFILE%\jarvis" apply "<הנתיב המלא לתיקייה הנוכחית>\jarvis-hebrew.patch". אם הוא לא נכנס נקי, תעצור ותראה לי למה. לא לנחש ולא לשכתב אותו.
4. תעתיק את start-jarvis.bat ו-open-jarvis.ps1 לתיקייה %USERPROFILE%\jarvis כמו שהם, בלי לשנות אותם.
5. בתיקייה %USERPROFILE%\jarvis: npm install, ואחר כך npm run build ו-npx --yes tsx scripts/check-i18n.ts. אם משהו נכשל, תתקן ותסביר לי בשתי שורות מה תיקנת.
6. npm run setup, ותוודא ש-Claude Code מחובר. אם לא, תבקש ממני להריץ claude פעם אחת ולהתחבר.
7. תבדוק שיש ב-Windows קול בעברית (ברישום, תחת HKLM:\SOFTWARE\Microsoft\Speech_OneCore\Voices\Tokens או HKLM:\SOFTWARE\Microsoft\Speech\Voices\Tokens, קול עם he-IL). אם אין, תסביר לי איך להוסיף: הגדרות ← זמן ושפה ← דיבור ← הוספת קולות ← עברית.
8. תיצור בשולחן העבודה (לפי [Environment]::GetFolderPath('Desktop')) קיצור דרך בשם JARVIS שמפעיל את %USERPROFILE%\jarvis\start-jarvis.bat.
9. בסוף תפעיל את start-jarvis.bat, ותגיד לי מה לעשות: ללחוץ "הפעלה" (או SKIP BOOT UP), לאשר את המיקרופון ולהגיד "היי ג'רוויס".

לא להפעיל מצב כתיבה (bridge:writes או start:workspace), ולא לשנות הגדרות מערכת בלי לשאול אותי.
```

## שימוש

- **"היי ג'רוויס"** מעיר אותו, ואז פשוט מדברים. אפשר גם בנשימה אחת: "היי ג'רוויס, מה מזג האוויר מחר?"
- **רווח (Space):** לדבר בלי מילת ההפעלה.
- **"עצור"**, **"די"** או **Esc:** עוצרים אותו באמצע משפט.
- **M:** השתקת המיקרופון. **V:** השתקת הקול שלו (התשובות נשארות על המסך). **D:** מסך אבחון.
- **HE / EN / PT** בצד ימין: מעבר שפה (הממשק, זיהוי הדיבור, מילת ההפעלה והקול).
- **SETTINGS:** בחירת מודל. Opus 5 הכי חכם, Sonnet 5 עונה מהר יותר.

## הקול בעברית

הקול החינמי הוא הקול העברי של Windows ("Asaf"): ברור, אבל נשמע רובוטי. אם הוא לא מותקן, ג'רוויס מציג הודעה עם ההוראות, ואפשר להוסיף אותו בהגדרות Windows ← זמן ושפה ← דיבור ← הוספת קולות ← עברית. אחר כך צריך לרענן את הדף.

קול טבעי יותר אפשרי בהמשך דרך שירות בתשלום, וזה ידרוש התאמה קטנה.

## מייל ויומן (בהמשך)

זו המלכודת מהפוסט: חיבורים שהוספתם ב-claude.ai לא נראים לג'רוויס. הוא רואה רק שרתי MCP שמוגדרים ל-Claude Code במחשב עצמו (בקובץ `~/.claude.json`). כשתרצו לחבר מייל ויומן, מוסיפים אותם שם, והם יופיעו ברשימת SYSTEMS בצד שמאל.

## מה השתנה בקוד המקורי

| קובץ | שינוי |
|---|---|
| `src/lib/i18n.ts` | שפה שלישית: עברית. 70 מחרוזות, בלי "אדוני" ובלי פנייה ממוגדרת |
| `src/lib/fillers.ts` | משפטי ביניים בעברית ("בודק את היומן.", "מחפש.") לכל כלי |
| `src/lib/voice.ts` | זיהוי דיבור ב-`he-IL`, ו"היי ג'רוויס" בכל האיותים (ג'רוויס, ג׳ארוויס, גרוויס, ג'רביס) |
| `src/App.tsx` | "עצור", "די", "חכה" עוצרים אותו, והשם בעברית מזוהה בתחילת פקודה |
| `src/lib/tts.ts` | בחירת קול עברי (טבעי אם יש, גברי אם אפשר), והודעה ברורה אם אין קול עברי |
| `src/store.ts` | דפדפן בעברית פותח את ג'רוויס בעברית |
| `src/ui/Hud.tsx` | כפתור HE, ושורות תמליל מימין לשמאל |
| `bridge/server.mjs` | הנחיה למודל: עברית מדוברת, בלי "אדוני", פנייה ניטרלית. וגם נתיב `claude.exe` ב-Windows |
| `bridge/whisper.mjs` | אפשרות לכבות את התמלול המקומי (אנגלית בלבד) |
| `package.json` | `bridge:writes` עובד גם ב-Windows |
| `scripts/check-i18n.ts` | הבדיקה העצמית מכסה עכשיו גם עברית |
